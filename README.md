# AI 에이전트 실습자료

AI 에이전트(Antigravity IDE)에게 문서 · 성적 · 연구 업무를 맡겨 보는 실습용 자료입니다.
모든 파일은 가상 기관 «한울대학교»의 **가상 자료**입니다. 이름 · 점수 · 측정값은 모두 지어낸 것이고 실제 기관 · 인물과 관계없습니다.

## 내려받기

1. 이 페이지 위쪽의 초록색 **Code** 버튼을 누르고 **Download ZIP**을 누릅니다.
   - 바로 받기: https://github.com/wdyd2004/ai-agent-practice-kit/archive/refs/heads/main.zip
2. 내려받은 zip 파일의 압축을 풉니다.
3. Antigravity IDE에서 **File › Open Folder**를 누르고 압축을 푼 폴더 안의 **실습자료** 폴더를 엽니다.

## 폴더 구성

| 폴더 | 들어 있는 자료 | 쓰는 실습 |
|---|---|---|
| 강의계획서 | 2026-2학기 강의계획서(워드) | ② 강의계획서 새 학기 판 |
| 중간고사 | 문제지 · 답안 · 채점표 | ③ 중간고사 결과 안내 |
| 기말 발표평가 | 평가자별 상호평가지 39개 · 팀 편성 · 평가 방법 | ④ 상호평가 → 기말 점수 |
| 과제 점수 | 과제 1 · 2 점수표 | ⑤ 총점 · 학점 · 검산 |
| 강의 자료 | 2027-1학기 강의계획서 · 7주차 강의 장표 | ⑦ 강의 장표 초안 · ⑧ 시험지 · 정답지 |
| 연구 자료 | 김치 발효 측정값 · 실험 노트 · 연구 계획서 · 보고서 양식 | ⑩ 연구 결과 보고서 초안 |

실습 ①(폴더 파악)은 실습자료 폴더 전체를, ⑥ · ⑨는 바로 앞 실습의 결과를 씁니다.

## 지킬 것

- 실제 학생 정보 · 성적 · 미공개 연구 자료는 넣지 않습니다. 실제 자료는 소속 기관의 AI 활용 지침을 확인한 뒤에 다룹니다.
- 에이전트가 원본을 고치지 않게 입력 문장에 «원본은 고치지 마»를 넣습니다.
